Conceito 1

🤔 O que é IA num jogo?

🧠 Definição simples

IA = um conjunto de regras que fazem o personagem agir sozinho, sem o jogador controlar!

SE condição → ENTÃO ação

🎮 Exemplos que você conhece

  • 🟢 Creeper (Minecraft)
    SE perto do jogador → explode
  • 🔴 Goomba (Mario)
    SE bater na parede → vira
  • 🟡 Fantasma (Pac-Man)
    SE pílula comida → foge
💡

No Construct 3, a IA é feita com Eventos (blocos de SE → ENTÃO) na Event Sheet. Não precisa saber código!

Conceito 2 — Essencial!

🔄 Máquina de Estados

Um personagem pode estar em diferentes estados. Quando algo acontece, ele troca de estado!

😴 PATRULHA
andando
→
jogador
perto
👀 AVISTOU
detectou
→
perseguir
🏃 PERSEGUE
correndo
→
perto
demais
⚔️ ATACA
dano

📦 Como guardar o estado?

Criamos uma Instance Variable no objeto chamada estado que guarda um texto:

"patrulha" "persegue" "ataca" "foge"

🎯 Na Event Sheet

Cada grupo de eventos só roda quando o estado é certo:

Inimigo.estado = "patrulha"
→ andar, virar na borda…
Inimigo.estado = "persegue"
→ correr em direção ao player…

Passo B · 1 de 5 — Inimigo

😈 Criando o Sprite do Inimigo

1

Dê duplo clique no layout → Sprite → Insert

2

Crie um desenho diferente do Player (cor vermelha, olho irritado…)

Sugestão: retângulo vermelho com dois olhos brancos!

4

No painel de propriedades, em Platform:

Passo B · 2 de 5 — Variáveis

📦 Adicionando Variáveis ao Inimigo

Variáveis guardam informações dentro do objeto. Vamos criar 3!

Como criar uma Instance Variable:

1

Clique com botão direito no objeto Inimigo no layout

2

Escolha "Instance variables…" no menu

3

Clique em "+" (Add variable)

4

Crie a variável estado:

📛 Name: estado · Type: Text · Value: "patrulha"

5

Crie a variável direcao:

📛 Name: direcao · Type: Number · Value: 1

1 = direita · -1 = esquerda

💡

direcao vale 1 (direita) ou -1 (esquerda) — com isso um só evento controla os dois lados!

Passo B · 4 de 5 — Eventos de Patrulha

😴 Evento 1 — Mover na Direção

Dentro do grupo "IA - Patrulha", clique em "Add event":

📌 Como adicionar um Evento:

1

Clique em "Add event" (dentro do grupo)

2

Selecione o objeto Inimigo → clique Next

3

Escolha a condição "Instance variable value"

Está em: Inimigo → Variables → Instance variable value

4

Configure: estado = "patrulha" → Done

📌 Adicionando Sub-eventos:

5

Clique direito no evento criado → "Add sub-event"

Condição: Inimigo → direcao = 1

6

Clique em "Add action" neste sub-evento:

Inimigo›Platform›Simulate control›Right
EVENTO 1 — dentro do grupo "IA - Patrulha"
🔵 Inimigo › estado = "patrulha"
↳ 🔵 Inimigo › direcao = 1
✅ Inimigo Platform › Simulate control: Right
↳ 🔵 Inimigo › direcao = -1
✅ Inimigo Platform › Simulate control: Left
Passo B · 5 de 6 — Virar na Borda

↩️ Evento 2 — Inimigo Vira na Borda

📌 Evento 2 — Virar quando não há chão na frente:

1

Add event → System → Compare two values
Inimigo.estado = "patrulha"

2

Add another condition:

Inimigo›Platform›Is on floor
3

Mais uma condição com Negate ✅:

Inimigo›Overlaps at offset

Object: Chao · X: Inimigo.direcao*32 · Y: 32

✅ Marque "Negate"! — checa se NÃO tem chão à frente

4

Action: Inimigo → Set direcao = Inimigo.direcao * -1

💡

Funciona como se o inimigo "olhasse pro chão" na frente — se não tiver chão, vira!

EVENTO 2 — grupo "IA - Patrulha"
🔵 Inimigo.estado = "patrulha"
🔵 Inimigo Platform › Is on floor
🔴 NOT Overlaps at offset Chao (X: dir*32, Y:32)
✅ Set direcao = Inimigo.direcao * -1
Passo B · 6 de 6 — Virar na Parede

🧱 Evento 3 — Inimigo Vira ao Bater na Parede

📌 Evento 3 — Virar ao colidir com parede:

1

Add event → System → Compare two values
Inimigo.estado = "patrulha"

2

Add another condition → Inimigo → Overlaps at offset (SEM Negate):

Object: Chao · X: Inimigo.direcao * 40 · Y: 0

Detecta parede na frente — sem Negate!

3

Action: Inimigo → Set direcao = Inimigo.direcao * -1

Inverte a direção — o inimigo "volta" da parede!

💡

Evento 2 = sem chão embaixo → vira. Evento 3 = parede na frente → vira. Juntos cobrem todos os casos!

EVENTO 3 — grupo "IA - Patrulha"
🔵 Inimigo.estado = "patrulha"
🔵 Overlaps at offset Chao (X: dir*40, Y:0)
✅ Set direcao = Inimigo.direcao * -1
Passo C · 1 de 4 — Detecção

👁️ Evento 3 — Inimigo Detecta o Jogador

Agora no grupo "IA - Detecção" — clique "Add event":

⚠️

Por que não usar distance()? Ela mede distância em X e Y — se o player está numa plataforma acima ou abaixo, a distância total cresce demais e o inimigo nunca detecta. Usamos só o eixo X!

1

Selecione System → Compare two values

Configure: Inimigo.estado = "patrulha"

2

Add another condition: System → Compare two values

First value: abs(Player.X - Inimigo.X)

Comparison: < (less than)

Second value: 200

abs() remove o sinal negativo — funciona igual para os dois lados!

3

Add action:

Inimigo›Instance variables›Set value

Variable: estado · Value: "persegue"

EVENTO 3 — grupo "IA - Detecção"
🔵 Inimigo.estado = "patrulha"
🔵 abs(Player.X - Inimigo.X) < 200
✅ Inimigo › Set estado = "persegue"
💡

Só X → detecta em qualquer altura! O inimigo vê o player mesmo que ele esteja em outra plataforma.

Passo C · 2 de 4 — Detecção

🚶 Evento 4 — Inimigo Perde o Jogador

Ainda no grupo "IA - Detecção" — "Add event":

1

System → Compare two values

Configure: Inimigo.estado = "persegue"

2

Add another condition

First value: abs(Player.X - Inimigo.X)

Comparison: > (greater than)

Second value: 250

Mesmo critério da detecção — só eixo X!

3

Add action: Inimigo → Set estado = "patrulha"

🎯

Por que 250 e não 200? Se fosse o mesmo valor, o inimigo ficaria trocando de estado toda hora (flickering). Usar um número maior cria um "amortecedor"!

EVENTO 4 — grupo "IA - Detecção"
🔵 System › Inimigo.estado = "persegue"
🔵 System › abs(Player.X - Inimigo.X) > 250
✅ Inimigo › Set estado = "patrulha"
RESUMO — Grupo "IA - Detecção" completo
🔵 estado="patrulha" AND abs(X) < 200 → persegue
🔵 estado="persegue" AND abs(X) > 250 → patrulha
Passo C · 3 de 4 — Perseguição

🏃 Evento 5 — Perseguir o Jogador

No grupo "IA - Perseguição" — "Add event":

1

System → Compare two values

Inimigo.estado = "persegue"

2

Add sub-event (clique direito no evento):

Sub-evento A — Player à DIREITA

System → Compare two values

Player.X > Inimigo.X

Action: Inimigo Platform → Simulate Right

3

Add sub-event (outro, no mesmo nível):

Sub-evento B — Player à ESQUERDA

System → Compare two values

Player.X < Inimigo.X

Action: Inimigo Platform → Simulate Left

EVENTO 5 — grupo "IA - Perseguição"
🔵 Inimigo.estado = "persegue"
↳ 🔵 Player.X > Inimigo.X
✅ Inimigo Platform → Simulate: Right
↳ 🔵 Player.X < Inimigo.X
✅ Inimigo Platform → Simulate: Left
Passo C · 4 de 4 — Perseguição

↩️ Evento 6 — Voltar ao Colidir com Parede

Ainda no grupo "IA - Perseguição" — mais um evento:

💡

Quando o inimigo está perseguindo e bate em uma parede (que não é o Player), ele inverte a direção — assim não fica preso!

1

System → Compare two values: Inimigo.estado = "persegue"

2

Add another condition → Inimigo → Overlaps at offset (SEM Negate):

Object: Chao · X: Inimigo.direcao * 40 · Y: 0

Parede na frente — sem Negate!

3

Add action:

Inimigo → Set direcao = Inimigo.direcao * -1

Inverte a direção ao bater na parede!

EVENTO 6 — grupo "IA - Perseguição"
🔵 Inimigo.estado = "persegue"
🔵 Overlaps at offset Chao (X: dir*40, Y:0)
✅ Set direcao = Inimigo.direcao * -1
▶️

Teste! O inimigo deve perseguir e virar ao bater em paredes. Aperte F5!

Passo D · 1 de 3 — NPC

🗣️ Criando o Sprite do NPC

1

Dê duplo clique no layout → Sprite → Insert

2

Desenhe um personagem amigável (verde, sorrindo, etc.)

Tamanho sugerido: 48×64 pixels

3

Nomeie como NPC

⚠️

NÃO adicione o Behavior Solid ao NPC!

Se o NPC tiver Solid, o Player nunca vai sobrepor ele — a detecção de proximidade não funciona. Vamos usar distance() para detectar quando o player está perto!

4

Clique direito no NPC → Instance variables… → crie:

📛 Name: npcFalando

🔢 Type: Number

🔢 Initial value: 0

0 = não está em diálogo · 1 = está falando

5

Crie um objeto Text → nomeie BalaoFala

Posicione acima do NPC → Properties → Initially visible: No

💡

npcFalando é um "semáforo": quando vale 1, nenhum outro evento sobrescreve o texto do balão!

Passo D · 2 de 4 — NPC

💬 Evento 7 — Mostrar Balão ao Aproximar

No grupo "NPC - Diálogo" — clique "Add event":

🐛

Por que não usar "Is overlapping"? Overlap roda todo tick enquanto sobrepõe → apaga o texto do balão toda hora. Com distance() e a variável npcFalando controlamos exatamente quando o texto muda!

1

Add event → System → Compare two values

First: distance(Player.X,Player.Y,NPC.X,NPC.Y)

Comparison: < (less than) · Second: 80

2

Add another condition → System → Compare two values

NPC.npcFalando = 0  ← só se NÃO está falando!

3

Actions:

1️⃣ BalaoFala → Set visible

2️⃣ BalaoFala → Set text: "Olá! Aperte E para falar! 👋"

EVENTO 7 — grupo "NPC - Diálogo"
🔵 distance(Player,NPC) < 80
🔵 NPC.npcFalando = 0
✅ BalaoFala → Set visible
✅ BalaoFala → Set text: "Olá! Aperte E para falar! 👋"
Passo D · 3 de 4 — NPC

🚶 Evento 8 — Esconder Balão ao Sair

Ainda no grupo "NPC - Diálogo" — "Add event":

1

Add event → System → Compare two values

First: distance(Player.X,Player.Y,NPC.X,NPC.Y)

Comparison: >= (greater or equal) · Second: 80

2

Actions:

1️⃣ BalaoFala → Set invisible

2️⃣ NPC → Set npcFalando = 0  ← reset ao sair!

💡

O reset do npcFalando aqui garante que ao voltar perto do NPC o balão aparece normalmente!

EVENTO 8 — grupo "NPC - Diálogo"
🔵 distance(Player,NPC) >= 80
✅ BalaoFala → Set invisible
✅ NPC → Set npcFalando = 0
▶️

Teste! Aperte F5 → aproxime do NPC → o balão aparece. Afaste → some!

Passo D · 4 de 4 — NPC

⌨️ Evento 9 — Tecla E para Falar

Ainda no grupo "NPC - Diálogo" — "Add event":

1

Selecione Keyboard → On key pressed

Clique no campo de tecla e aperte E no teclado

2

Add another condition → System → Compare two values

First: distance(Player.X,Player.Y,NPC.X,NPC.Y)

Comparison: < · Second: 80

3

Add another condition → System → Compare two values

NPC.npcFalando = 0  ← evita disparar duas vezes!

4

Actions em ordem:

1️⃣ NPC → Set npcFalando = 1 ← trava o Evento 7!

2️⃣ BalaoFala → Set text: "Boa sorte, herói! ⚔️"

3️⃣ System → Wait 3 seconds

4️⃣ BalaoFala → Set text: "Até logo! 👋"

5️⃣ System → Wait 1 second

6️⃣ NPC → Set npcFalando = 0 ← libera de novo!

EVENTO 9 — grupo "NPC - Diálogo"
🔵 Keyboard › On key E pressed
🔵 distance(Player,NPC) < 80
🔵 NPC.npcFalando = 0
✅ NPC → Set npcFalando = 1
✅ BalaoFala → Set text: "Boa sorte, herói! ⚔️"
✅ System → Wait 3 s
✅ BalaoFala → Set text: "Até logo! 👋"
✅ System → Wait 1 s
✅ NPC → Set npcFalando = 0
▶️

Teste! Aperte F5 → aproxime do NPC → aperte E. O balão não deve mais piscar!
